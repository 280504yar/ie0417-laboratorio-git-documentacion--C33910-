Introducción a NumPy
====================

NumPy es una biblioteca de código abierto orientada a la computación numérica
en Python. Proporciona estructuras de datos eficientes para trabajar con
arreglos multidimensionales y una amplia colección de funciones matemáticas.

Esta documentación fue generada mediante Sphinx como parte del laboratorio de
Git y documentación de software.

Proyecto original
-----------------

El repositorio oficial del proyecto es:

https://github.com/numpy/numpy

Organización general
--------------------

NumPy está organizado en diferentes módulos que proporcionan funcionalidades
para la manipulación de arreglos multidimensionales, operaciones matemáticas,
álgebra lineal, generación de números aleatorios y otras herramientas de
computación científica.

La referencia de API incluida en esta documentación se obtiene a partir del
código fuente y de los docstrings presentes en el proyecto.
