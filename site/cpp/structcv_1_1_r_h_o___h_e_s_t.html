Base Struct for RHO algorithm.

A RHO estimator has initialization, finalization, capacity, seeding and homography-estimation APIs that must be implemented.

◆ ensureCapacity()

virtual int cv::RHO_HEST::ensureCapacity ( unsigned N,
double beta )
inlinevirtual

Ensure that the estimator context's internal table for the non-randomness criterion is at least of the given size, and uses the given beta. The table should be larger than the maximum number of matches fed into the estimator.

A value of N of 0 requests deallocation of the table.

Parámetros
[in]NIf 0, deallocate internal table. If > 0, ensure that the internal table is of at least this size, reallocating if necessary.
[in]betaThe beta-factor to use within the table.
Devuelve
0 if unsuccessful; non-zero otherwise.

virtual double cv::RHO_HEST::fastRandom ( void )

Generates a random double uniformly distributed in the range [0, 1).

The default implementation uses the xorshift128+ algorithm from Sebastiano Vigna. Further scramblings of Marsaglia's xorshift generators. CoRR, abs/1402.6246, 2014. http://vigna.di.unimi.it/ftp/papers/xorshiftplus.pdf

Source roughly as given in http://en.wikipedia.org/wiki/Xorshift#Xorshift.2B

Estimates the homography using the given context, matches and parameters to PROSAC.

Parámetros
[in]srcThe pointer to the source points of the matches. Cannot be NULL.
[in]dstThe pointer to the destination points of the matches. Cannot be NULL.
[out]inlThe pointer to the output mask of inlier matches. May be NULL.
[in]NThe number of matches.
[in]maxDThe maximum distance.
[in]maxIThe maximum number of PROSAC iterations.
[in]rConvgThe RANSAC convergence parameter.
[in]cfdThe required confidence in the solution.
[in]minInlThe minimum required number of inliers.
[in]betaThe beta-parameter for the non-randomness criterion.
[in]flagsA union of flags to control the estimation.
[in]guessHAn extrinsic guess at the solution H, or NULL if none provided.
[out]finalHThe final estimation of H, or the zero matrix if the minimum number of inliers was not met. Cannot be NULL.
Devuelve
The number of inliers if the minimum number of inliers for acceptance was reached; 0 otherwise.
