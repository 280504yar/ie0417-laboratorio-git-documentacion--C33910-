1#!/usr/bin/env python
2""" OpenCV performance test results charts generator.
3
4This script formats results of a performance test as a table or a series of tables according to test
5parameters.
6
7### Description
8
9Performance data is stored in the GTest log file created by performance tests. Default name is
10`test_details.xml`. It can be changed with the `--gtest_output=xml:<location>/<filename>.xml` test
11option. See https://github.com/opencv/opencv/wiki/HowToUsePerfTests for more details.
12
13Script accepts an XML with performance test results as an input. Only one test (aka testsuite)
14containing multiple cases (aka testcase) with different parameters can be used. Test should have 2
15or more parameters, for example resolution (640x480), data type (8UC1), mode (NORM_TYPE), etc.
16Parameters #2 and #1 will be used as table row and column by default, this mapping can be changed
17with `-x` and `-y` options. Parameter combination besides the two selected for row and column will
18be represented as a separate table. I.e. one table (RES x TYPE) for `NORM_L1`, another for
19`NORM_L2`, etc.
20
21Test can be selected either by using `--gtest_filter` option when running the test, or by using the
22`--filter` script option.
23
24### Options:
25
26-f REGEX, --filter=REGEX - regular expression used to select a test
27-x ROW, -y COL - choose different parameters for rows and columns
28-u UNITS, --units=UNITS - units for output values (s, ms (default), us, ns or ticks)
29-m NAME, --metric=NAME - output metric (mean, median, stddev, etc.)
30-o FMT, --output=FMT - output format ('txt', 'html' or 'auto')
31
32### Example:
33
34./chart.py -f sum opencv_perf_core.xml
35
36Geometric mean for
37sum::Size_MatType::(Y, X)
38
39 X\Y 127x61 640x480 1280x720 1920x1080
408UC1 0.03 ms 1.21 ms 3.61 ms 8.11 ms
418UC4 0.10 ms 3.56 ms 10.67 ms 23.90 ms
4232FC1 0.05 ms 1.77 ms 5.23 ms 11.72 ms
43"""
