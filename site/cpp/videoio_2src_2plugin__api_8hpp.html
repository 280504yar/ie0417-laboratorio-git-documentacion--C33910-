#define ABI_VERSION   0

increased for incompatible changes, e.g. remove function argument Caller ABI == Plugin ABI -> plugin is compatible Caller ABI > Plugin ABI -> plugin is not compatible, caller should use shim code to use old ABI plugins (caller may know how lower ABI works, so it is possible) Caller ABI < Plugin ABI -> plugin can't be used (plugin should provide interface with lower ABI to handle that)
