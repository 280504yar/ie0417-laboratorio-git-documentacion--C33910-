Descripción detallada

One operand's slice for the current tile: base pointer + steps in ELEMENTS. stepx in {0,1} (1 = contiguous along width, 0 = broadcast-scalar); stepy = step between the height rows (0 = broadcast). ptr is non-const so the body can write the operand(s) it treats as outputs.
