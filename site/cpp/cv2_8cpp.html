◆ createSubmodule()

PyObject * createSubmodule ( PyObject * parent_module,
const std::string & name )
static

Creates a submodule of the root. Missing parents submodules are created as needed. If name equals to parent module name than borrowed reference to parent module is returned (no reference counting are done). Submodule lifetime is managed by the parent module. If nested submodules are created than the lifetime is managed by the predecessor submodule in a list.

Parámetros
parent_moduleParent module object.
nameSubmodule name.
Devuelve
borrowed reference to the created submodule. If any of submodules can't be created than NULL is returned.

Special case handling when caller tries to register a submodule of the parent module with the same name

There is no intermediate submodules in the provided name

If submodule already exists it can be found in the parent module dictionary, otherwise it should be added to it.

Populates global modules dictionary and returns borrowed reference to it

Return PyImport_AddModule NULL with an exception set on failure.

Populates parent module dictionary. Submodule lifetime should be managed by the global modules dictionary and parent module dictionary, so Py_DECREF after successful call to the PyDict_SetItemString is redundant.
