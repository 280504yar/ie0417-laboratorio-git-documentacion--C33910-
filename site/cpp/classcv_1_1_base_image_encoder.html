Descripción detallada

Base class for image encoders.

The BaseImageEncoder class provides an abstract interface for encoding images in various formats. It defines common functionality like setting the destination (file or memory buffer), checking if the format supports a specific image depth, and writing image data. Derived classes must implement methods like writing the image data to handle format-specific encoding logic.
