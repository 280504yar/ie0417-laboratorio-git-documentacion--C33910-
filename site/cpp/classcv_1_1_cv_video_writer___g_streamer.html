CvVideoWriter_GStreamer::open.

Parámetros
filenamefilename to output to
fourccdesired codec fourcc
fpsdesired framerate
frameSizethe size of the expected frames
paramsother parameters
Devuelve
success

We support 2 modes of operation. Either the user enters a filename and a fourcc code, or enters a manual pipeline description like in CvVideoCapture_GStreamer. In the latter case, we just push frames on the appsink with appropriate caps. In the former case, we try to deduce the correct container from the filename, and the correct encoder from the fourcc profile.

If the file extension did was not recognize, an avi container is used
