const String & obj_name,
InputArray verts,

Shows a mesh object in the specified viz3d window. See cv::viz3d::destroyObject.

The vertices array must be 2D. If shading is disabled (the default option), each row has a width of 3 (xyz), 6 (xyz, rgb) or 9 (xyz, rgb, uvw) where uvw is the normal, so that each row represents a vertex. Shading is only enabled when using normals.
