Descripción detallada

Backend-independent description of a graph operation (node).

LayerInfo carries everything needed to reason about an operation without executing it: its parameters (blobs and type-specific fields of derived classes), graph wiring (inputs / outputs as Arg indices) and shape/type/layout inference. The new DNN graph engine stores a topologically sorted sequence of LayerInfo nodes (see Graph::prog()); executable, backend-specific instances (Layer subclasses) are constructed from an LayerInfo during Net::finalizeNet().

Each operation type registers a static Ptr<LayerInfo> create(const LayerParams&) factory via CV_DNN_REGISTER_OP_CLASS.
