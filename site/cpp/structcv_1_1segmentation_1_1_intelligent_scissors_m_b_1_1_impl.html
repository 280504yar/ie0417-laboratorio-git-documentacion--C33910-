◆ add_local_cost()

bool cv::segmentation::IntelligentScissorsMB::Impl::add_local_cost ( const Point & p,
const Point & q,
float & cost_p,
const float cost_q ) const
inline

Adds local_cost(p, q) to cost_p.

local_cost(p, q) is computed as weight_non_edge_compute * non_edge_feature.at<uchar>(q) + weight_gradient_direction * fD + weight_gradient_magnitude * fG

Parámetros
ppoint p (input)
qpoint q (input)
cost_pcost for p (input/output)
cost_qcost for q (input)
Devuelve
The boolean result of the (cost_p < cost_q) comparison.
Nota
The computed output cost_p can be partial if (cost_p < cost_q) is false.
