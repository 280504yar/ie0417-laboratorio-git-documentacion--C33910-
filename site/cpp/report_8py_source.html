2""" Print performance test run statistics.
3
4Performance data is stored in the GTest log file created by performance tests. Default name is
5`test_details.xml`. It can be changed with the `--gtest_output=xml:<location>/<filename>.xml` test
6option. See https://github.com/opencv/opencv/wiki/HowToUsePerfTests for more details.
7
8This script produces configurable performance report tables in text and HTML formats. It allows to
9filter test cases by name and parameter string and select specific performance metrics columns. One
10or multiple test results can be used for input.
11
12### Example
13
14./report.py -c min,mean,median -f '(LUT|Match).*640' opencv_perf_core.xml opencv_perf_features.xml
