16/* Assigns buffers for all intermediate tensors of the graph/model
17
18 The algorithm is quite simple, but there are some nuances in the attempt to re-use memory more efficiently:
19
20 All layer arguments in graph and sub-graphs are classified into 4 categories:
21 a) inputs, b) outputs, c) constants and d) temporary values/tensors.
22
23 Except for the temporary values ("d" category), each other argument gets
24 its own dedicated storage, which makes things more clear and predictable.
25 So, this algorithm assigns buffers only for the temporary values.
26
27 During the inference process, each temporary value is computed
28 by one of the layers and then used by zero or more subsequent layers (only as input).
29 An example of a model where some tensors are used more than once is Resnet.
30 After a tensor is used for the last time and
31 won't be used in any subsequent layer, the memory buffer for that tensor could be re-used for
32 other arguments. We want to assign each temporary tensor to some temporary buffer,
33 and it's typically N:1 mapping.
34
35 We do it using 2-stage algorithm:
36
37 1. First, we calculate, how many times each argument is used and store the counters into 'usecounts'.
38 2. Second, we scan the layers in topologically sorted order
39 2.0. Sanity check: We check that each input argument of the operation is either input or constant,
40 or it's a temporary tensor with the buffer assigned to it.
41 If not, then the layers are not sorted in a topological order.
42 2.1. For in-place reshape operations, such as squeeze/unsqueeze/flatten etc.
43 or for unary element-wise operations,
44 we check whether the input is a temporary value and is not used in any subsequent operations.
45 If these checks all pass, we assign output argument to the same buffer as input. Note that
46 we don't try to reuse inputs of binary/ternary etc. operation because of the broadcasting.
47 We need to do symbolic shape inference to proof that the output is of the same shape as one of the inputs.
48 2.2. Otherwise, for each output argument of operation, which is not a network output argument.
49 we assign the most recently-used free buffer (i.e. the top buffer in the stack of free buffers).
50 If there is no free buffers, i.e. the stack is empty, we create a new buffer, and use it.
51 2.3. For each input we decrement the corresponding element of 'usecounts'. If the counter reaches 0 and the input
52 is not aliased with one of the outputs (see 2.1),
53 we push the corresponding buffer index into the stack of free buffers.
54 2.4. In the case of in-place operations and sometimes when using subgraphs (e.g. in If, Loop operations) we may
55 re-use the same buffer for several arguments
56 (which can be ouputs for some operations and inputs for some subsequent operations).
57 In order to handle it all properly, during the buffer assignment algorithm we maintain use counter for each
58 buffer, which should not be confused with use counters for arguments. A pool of free buffers contains zero or
59 more "spare" buffers with 0 use counts. A buffer in use has the corresponding usage count > 0.
60 When some argument is not needed anymore, and if it's not a constant, it decrements the usage counter of the buffer
61 where it resides. When the counter reaches zero, we return the buffer into the pool of free buffers and then
62 we can reuse the same buffer for another argument (or probably different shape and/or type, see below).
63 In principle, we could 'protect' some buffers from the premature release and re-use by incrementing the use counts
64 of the respective arguments that reside in those buffers, but that would make the bookkeeping much more complex.
65
66 Please, note that when we reuse buffers, we don't check any types, shape or a total size of the buffer needed.
67 We reallocate each buffer at runtime to fit each single argument that it's used for. For example, let's say the buffer #3
68 is used for arguments #5 (10x10x10 FP32), #10 (6x6x32 FP32) and #14 (300x1 UINT64). Then during the the first run of
69 the inference the buffer #3 will be reallocated from 0 bytes to 1000*4 bytes to fit arg #10,
70 then from 4000 to 6*6*32*4=4608 bytes to fit arg #10 and then it will fit arg #14 without reallocations.
71 During the second run of inference with the same resolution input the buffer will not be reallocated.
72
73 The reallocation is done using Buffer.fit() function.
74 */

87 /*
88 Here are 3 workhorse methods that abstract the use and bookkeeping of buffers:
89 1. getFreeBuffer() takes the first spare buffer from the pool of free buffers. Since
90 we don't necessarily know the shape/type of tensor type at this stage, this is quite
91 reasonable behaviour - we cannot do anything more complex that that. On the positive side,
92 since the pool of free buffers operates like a stack, the first free buffer is the most
93 recently released buffer, so we improve cache locality using this pattern.
94 When we don't have spare buffers in the pool, we "virtually" create a new buffer
95 (by incrementing the number of buffers used) and return it.
96
97 For the retrieved buffer we set its use count to 1.
98 2. releaseBuffer(bufidx) decrements the buffer use count and returns it to the pool
99 of free buffers as long as the use counter reaches 0.
100 3. shareBuffer(from_arg, to_arg) takes two argument indices.
101 It makes argument 'to_arg' use the same buffer as 'from_arg'.
102 Use counter for the assigned to 'to_arg' buffer (if any) is decremented.
103 Use counter for the 'from_arg' buffer is incremented, correpondingly.
104 */
105
106 int getFreeBuffer()
107 {
108 if (freebufs.empty()) {
109 freebufs.push_back(nbufs);
110 buf_usecounts.push_back(0);
111 //printf("added buf %d\n", nbufs);
112 nbufs++;
113 }
114 int outidx = freebufs.back();
115 freebufs.pop_back();
116 buf_usecounts[outidx] = 1;
117 return outidx;
118 }
119
120 void releaseBuffer(int bufidx)
121 {
122 if (bufidx >= 0) {
123 CV_Assert(buf_usecounts[bufidx] > 0);
124 if (--buf_usecounts[bufidx] == 0)
125 freebufs.push_back(bufidx);
126 }
127 }
128
129 void shareBuffer(Arg fromArg, Arg toArg)
130 {
131 CV_Assert(!netimpl->isConstArg(fromArg) && !netimpl->isConstArg(toArg));
132 int fromBuf = bufidxs[fromArg.idx], toBuf = bufidxs[toArg.idx];
133 CV_Assert(fromBuf >= 0);
134 bufidxs[toArg.idx] = fromBuf;
135 buf_usecounts[fromBuf]++;
136 if (toBuf >= 0)
137 releaseBuffer(toBuf);
138 }

140 // Allocate a Loop/Scan body, keeping its closure (outer-scope) args alive across it.
141 void assignSubgraphKeepingClosure(const Ptr<Graph>& body)
142 {
143 std::unordered_set<int> bodyDefined;
144 for (Arg ba : body->inputs())
145 bodyDefined.insert(ba.idx);
146 for (const Ptr<LayerInfo>& blayer : body->prog()) {
147 if (!blayer) continue;
148 for (Arg bo : blayer->outputs)
149 bodyDefined.insert(bo.idx);
150 }
151 std::unordered_set<int> closureBumped;
152 for (const Ptr<LayerInfo>& blayer : body->prog()) {
153 if (!blayer) continue;
154 for (Arg bi : blayer->inputs) {
155 if (bi.idx <= 0) continue;
156 if (bodyDefined.count(bi.idx)) continue;
157 if (netimpl->isConstArg(bi)) continue;
158 if (bufidxs[bi.idx] < 0) continue;
159 if (closureBumped.insert(bi.idx).second) {
160 usecounts[bi.idx]++;
161 buf_usecounts[bufidxs[bi.idx]]++;
162 }
163 }
164 }
165
166 std::vector<int> saved_freebufs = freebufs;
167 freebufs.clear();
168 assign(body);
169 freebufs = saved_freebufs;
170
171 for (int idx : closureBumped) {
172 int bidx = bufidxs[idx];
173 if (--usecounts[idx] == 0) {
174 if (bidx >= 0)
175 releaseBuffer(bidx);
176 } else if (bidx >= 0) {
177 CV_Assert(buf_usecounts[bidx] > 0);
178 --buf_usecounts[bidx];
179 }
180 }
181 }

196 void assign()
197 {
198 netimpl->useCounts(usecounts);
199 size_t nargs = usecounts.size();
200 bufidxs.assign(nargs, -1);
201 nbufs = 0;
202 assign(netimpl->mainGraph);
203 netimpl->bufidxs = bufidxs;
204 netimpl->buffers.resize(nbufs);
205 for (int i = 0; i < nbufs; i++)
206 netimpl->buffers[i] = Mat();
207 }

209 void assign(const Ptr<Graph>& graph)
210 {
211 if (!graph)
212 return;
213 // Pre-assign buffers for *sub-graph* TEMP inputs/outputs only.
214 // (The main graph has already been handled by regular allocation logic.)
215 bool isSubGraph = graph.get() != netimpl->mainGraph.get();
216 if (isSubGraph)
217 {
218 const std::vector<Arg>& gr_inputs = graph->inputs();
219 for (const Arg& inarg : gr_inputs)
220 {
221 if (netimpl->argKind(inarg) == DNN_ARG_TEMP &&
222 !netimpl->isConstArg(inarg) &&
223 bufidxs.at(inarg.idx) < 0)
224 {
225 bufidxs.at(inarg.idx) = getFreeBuffer();
226 }
227 }
228 }
229 const std::vector<Ptr<LayerInfo> >& prog = graph->prog();
230 for (const auto& layer: prog) {
231 bool inplace = false;
232 Arg reuseArg;
233
234 if (!layer) continue;
235
236 const std::vector<Arg>& inputs = layer->inputs;
237 const std::vector<Arg>& outputs = layer->outputs;
238 size_t ninputs = inputs.size();
239 size_t noutputs = outputs.size();
240
241 //std::cout << "graph '" << graph->name() << "', op '" << layer->name << "' (" << layer->type << ")\n";
242 //std::cout << "usecounts: " << usecounts << "\n";
243 //dumpArgVec(std::cout, "usecounts", usecounts) << "\n";
244 //std::cout << "freebufs: " << freebufs << "\n";
245 //std::cout << "buf_usecounts: " << buf_usecounts << "\n";
246 //dumpArgVec(std::cout, "bufidxs", bufidxs) << "\n";
247
248 /*
249 Determine if we can possibly re-use some of the input buffers for the output as well,
250 in other words, whether we can run the operation in-place.
251 Not only it saves memory, but it can also:
252 1. improve L2/L3 cache re-use
253 2. effectively convert some copy/re-shape operations
254 (Identity, Flatten, Reshape, Squeeze, Unsqueeze)
255 into Nop (no-operation).
256 */
257 //const ElemwiseOp* elemwise_op = dynamic_cast<const ElemwiseOp*>(op);
258
259 if (/*dynamic_cast<const BatchNormOp*>(op) != 0 ||
260 dynamic_cast<const FlattenOp*>(op) != 0 ||
261 (elemwise_op != 0 && elemwise_op->getActivation(CV_32F) != 0) ||
262 dynamic_cast<const ReshapeOp*>(op) != 0 ||
263 dynamic_cast<const SqueezeOp*>(op) != 0 ||
264 dynamic_cast<const UnsqueezeOp*>(op) != 0*/
265 layer->alwaysSupportInplace()) {
266 CV_Assert(ninputs >= 1);
267 Arg inp0 = inputs[0];
268 inplace = netimpl->argKind(inp0) == DNN_ARG_TEMP && usecounts[inp0.idx] == 1;
269 reuseArg = inp0;
270 }
271
272 /*
273 Unless the operation is in-place, assign buffers for each output.
274 We do it before we recursively process subgraphs inside If/Loop/Scan.
275 this way we avoid any possible influence of buffer allocation inside a subgraph
276 to the parent graphs.
277 */
278 //if (layer->type == "Softmax")
279 // putchar('.');
280 if (noutputs > 0) {
281 Arg out0 = outputs[0];
282 if (inplace &&
283 noutputs == 1 &&
284 netimpl->argKind(out0) == DNN_ARG_TEMP &&
285 bufidxs.at(out0.idx) < 0)
286 shareBuffer(reuseArg, out0);
287 else {
288 for (auto out: outputs) {
289 if (netimpl->argKind(out) == DNN_ARG_TEMP &&
290 bufidxs.at(out.idx) < 0) {
291 bufidxs.at(out.idx) = getFreeBuffer();
292 }
293 }
294 }
295 }
296
297 std::string opname = layer->type;
298
299 if (opname == "If") {
300 /*
301 Pre-allocate buffers for the output nodes of then- and else- branches.
302 We try to alias them with the corresponding t_out[i] elements, so
303 that we save one copy operation.
304 [TODO]
305 It's not the most optimal buffer allocation.
306 In the ideal case, e.g. when both then- and else- branches
307 are just sequences of element-wise operations that can be executed in-place,
308 we could simply use a single buffer for both then- and else- branches.
309 Here we will use separate buffers, but let's assume we could
310 optimize out such trivial branches at the graph fusion level
311 (especially when we have JIT).
312 */
313 auto branches = layer->subgraphs();
314 CV_Assert(branches->size() == 2);
315
316 const Ptr<Graph>& thenBranch = branches->at(0);
317 const Ptr<Graph>& elseBranch = branches->at(1);
318 const vector<Arg>& thenOutargs = thenBranch->outputs();
319 const vector<Arg>& elseOutargs = elseBranch->outputs();
320 CV_Assert(thenOutargs.size() == noutputs && elseOutargs.size() == noutputs);
321 for (size_t i = 0; i < noutputs; i++) {
322 Arg outarg = outputs[i];
323 Arg thenOutarg = thenOutargs[i];
324 Arg elseOutarg = elseOutargs[i];
325
326 if (!netimpl->isConstArg(thenOutarg) &&
327 usecounts[thenOutarg.idx] == 1 &&
328 bufidxs[thenOutarg.idx] >= 0)
329 shareBuffer(outarg, thenOutarg);
330 if (!netimpl->isConstArg(elseOutarg) &&
331 usecounts[elseOutarg.idx] == 1 &&
332 bufidxs[thenOutarg.idx] >= 0)
333 shareBuffer(outarg, elseOutarg);
334 }
335
336 // Isolate subgraph buffers: prevent parent's freed buffers from
337 // being reused here, which causes overwrites on re-execution.
338 std::vector<int> saved_freebufs = freebufs;
339 freebufs.clear();
340 assign(thenBranch);
341 freebufs.clear();
342 assign(elseBranch);
343 freebufs = saved_freebufs;
344
345 for (size_t i = 0; i < noutputs; i++) {
346 Arg thenOutarg = thenOutargs[i];
347 Arg elseOutarg = elseOutargs[i];
348 if (!netimpl->isConstArg(thenOutarg) &&
349 bufidxs[thenOutarg.idx] >= 0 &&
350 !netimpl->isConstArg(elseOutarg) &&
351 bufidxs[elseOutarg.idx] >= 0)
352 shareBuffer(thenOutarg, elseOutarg);
353 }
354 } else if (opname == "Loop") {
355 /*
356 In the case of loop we try to alias t_v_in[i] and t_v_out[i] so that
357 we eliminate some copy operations after each loop iteration.
358 */
359 //LoopLayer* loop = dynamic_cast<LoopLayer*>(op);
360 CV_Assert(ninputs >= 2);
361 auto subgraphs = layer->subgraphs();
362 CV_Assert(subgraphs && subgraphs->size() == 1);
363 const Ptr<Graph>& body = subgraphs->at(0);
364 Arg trip_count = inputs[0];
365 const std::vector<Arg>& body_inputs = body->inputs();
366 const std::vector<Arg>& body_outputs = body->outputs();
367 size_t body_ninputs = body_inputs.size();
368 size_t body_noutputs = body_outputs.size();
369 int n_state_vars = (int)(ninputs - 2);
370 int n_accums = (int)(body_noutputs - n_state_vars - 1);
371 CV_Assert(body_ninputs == ninputs);
372 CV_Assert(body_noutputs == noutputs+1);
373 CV_Assert(n_state_vars >= 0 && n_accums >= 0);
374 Arg inp0 = inputs[0];
375 if (inp0.idx > 0 && usecounts[inp0.idx] > 0 &&
376 !netimpl->isConstArg(inp0)) {
377 if (!netimpl->isConstArg(trip_count) && bufidxs[trip_count.idx] >= 0)
378 shareBuffer(trip_count, inputs[0]);
379 else
380 bufidxs.at(inputs[0].idx) = getFreeBuffer();
381 }
382
383 for (int i = -1; i < n_state_vars; i++) {
384 Arg inparg = body_inputs[i+2];
385 Arg outarg = body_outputs[i+1];
386 Arg v_inp = inputs[i+2];
387 Arg v_out = i >= 0 ? outputs[i] : Arg();
388 if (inparg.idx > 0 && usecounts[inparg.idx] > 0) {
389 CV_Assert(!netimpl->isConstArg(inparg));
390 if (!netimpl->isConstArg(v_inp) && v_inp.idx > 0 && bufidxs[v_inp.idx] >= 0)
391 shareBuffer(v_inp, inparg);
392 else
393 bufidxs[inparg.idx] = getFreeBuffer();
394 }
395 if (!netimpl->isConstArg(v_out)) {
396 if (!netimpl->isConstArg(outarg) && usecounts[outarg.idx] == 1)
397 shareBuffer(v_out, outarg);
398 }
399 }
400
401 assignSubgraphKeepingClosure(body);
402 } else if (opname == "Scan") {
403 auto subgraphs = layer->subgraphs();
404 CV_Assert(subgraphs && subgraphs->size() == 1);
405 assignSubgraphKeepingClosure(subgraphs->at(0));
406 }
407
408 for (auto out: outputs) {
409 if (usecounts[out.idx] == 0)
410 releaseBuffer(bufidxs.at(out.idx));
411 }
412 // let's release inputs in the reverse order to keep the buffer allocation consistent across the network
413 for (size_t i = 0; i < ninputs; i++) {
414 Arg inp = inputs[ninputs-i-1];
415 int bufidx = bufidxs[inp.idx];
416 if (bufidx >= 0) {
417 if (--usecounts.at(inp.idx) == 0)
418 releaseBuffer(bufidx);
419 }
420 }
421 }
422 }
