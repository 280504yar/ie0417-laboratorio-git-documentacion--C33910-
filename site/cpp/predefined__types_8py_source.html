7# Set of predefined types used to cover cases when library doesn't
8# directly exports a type and equivalent one should be used instead.
9# Example: Instead of C++ `cv::Rect(1, 1, 5, 6)` in Python any sequence type
10# with length 4 can be used: tuple `(1, 1, 5, 6)` or list `[1, 1, 5, 6]`.
11# Predefined type might be:
12# - alias - defines a Python synonym for a native type name.
13# Example: `cv::Rect` and `cv::Size` are both `Sequence[int]` in Python, but
14# with different length constraints (4 and 2 accordingly).
15# - direct substitution - just a plain type replacement without any credits to
16# native type. Example:
17# * `std::vector<uchar>` is `np.ndarray` with `dtype == np.uint8` in Python
18# * `double` is a Python `float`
19# * `std::string` is a Python `str`
