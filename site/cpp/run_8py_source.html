2""" Test runner and results collector for OpenCV
3
4This script abstracts execution procedure for OpenCV tests. Target scenario: running automated tests
5in a continuous integration system.
6See https://github.com/opencv/opencv/wiki/HowToUsePerfTests for more details.
7
8### Main features
9
10- Collect test executables, distinguish between accuracy and performance, main and contrib test sets
11- Pass through common GTest and OpenCV test options and handle some of them internally
12- Set up testing environment and handle some OpenCV-specific environment variables
13- Test Java and Python bindings
14- Test on remote android device
15- Support valgrind, qemu wrapping and trace collection
16
17### Main options
18
19-t MODULES, --tests MODULES - Comma-separated list of modules to test (example: -t core,imgproc,java)
20-b MODULES, --blacklist MODULES - Comma-separated list of modules to exclude from test (example: -b java)
21-a, --accuracy - Look for accuracy tests instead of performance tests
22--check - Shortcut for '--perf_min_samples=1 --perf_force_samples=1'
23-w PATH, --cwd PATH - Working directory for tests (default is current)
24-n, --dry_run - Do not run anything
25-v, --verbose - Print more debug information
26
27### Example
28
29./run.py -a -t core --gtest_filter=*CopyTo*
30
31Run: /work/build-opencv/bin/opencv_test_core --gtest_filter=*CopyTo* --gtest_output=xml:core_20221017-195300.xml --gtest_color=yes
