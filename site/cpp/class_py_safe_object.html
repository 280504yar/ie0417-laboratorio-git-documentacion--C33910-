Descripción detallada

Light weight RAII wrapper for PyObject* owning references. In comparison to C++11 std::unique_ptr with custom deleter, it provides implicit conversion functions that might be useful to initialize it with Python functions those returns owning references through the PyObject** e.g. PyErr_Fetch or directly pass it to functions those want to borrow reference to object (doesn't extend object lifetime) e.g. PyObject_Str.
