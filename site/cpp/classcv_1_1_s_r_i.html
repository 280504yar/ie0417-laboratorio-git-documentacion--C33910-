Descripción detallada

template<typename T>
class cv::SRI< T >

Given a set of 3d points in a depth image, compute the normals at each point using the SRI method described in Fast and Accurate Computation of Surface Normals from Range Images by H. Badino, D. Huber, Y. Park and T. Kanade
