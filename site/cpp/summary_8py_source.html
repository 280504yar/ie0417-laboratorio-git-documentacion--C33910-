1#!/usr/bin/env python
2""" Format performance test results and compare metrics between test runs
3
4Performance data is stored in the GTest log file created by performance tests. Default name is
5`test_details.xml`. It can be changed with the `--gtest_output=xml:<location>/<filename>.xml` test
6option. See https://github.com/opencv/opencv/wiki/HowToUsePerfTests for more details.
7
8This script allows to compare performance data collected during separate test runs and present it in
9a text, Markdown or HTML table.
10
11### Major options
12
13-o FMT, --output=FMT - output format ('txt', 'html', 'markdown', 'tabs' or 'auto')
14-f REGEX, --filter=REGEX - regex to filter tests
15-m NAME, --metric=NAME - output metric
16-u UNITS, --units=UNITS - units for output values (s, ms (default), us, ns or ticks)
17
18### Example
19
20./summary.py -f LUT.*640 core1.xml core2.xml
21
22Geometric mean (ms)
23
24 Name of Test core1 core2 core2
25 vs
26 core1
27 (x-factor)
28LUT::OCL_LUTFixture::(640x480, 8UC1) 2.278 0.737 3.09
29LUT::OCL_LUTFixture::(640x480, 32FC1) 2.622 0.805 3.26
30LUT::OCL_LUTFixture::(640x480, 8UC4) 19.243 3.624 5.31
31LUT::OCL_LUTFixture::(640x480, 32FC4) 21.254 4.296 4.95

33"""
