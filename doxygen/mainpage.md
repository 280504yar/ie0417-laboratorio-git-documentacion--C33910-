# OpenCV - Documentación técnica {#mainpage}

Esta documentación fue generada mediante **Doxygen** a partir del código fuente
del proyecto **OpenCV (Open Source Computer Vision Library)** como parte del
laboratorio de Git y documentación de software.

## Proyecto original

OpenCV es una biblioteca de software libre orientada al procesamiento de
imágenes, visión por computadora y aprendizaje automático.

Repositorio original:

https://github.com/opencv/opencv

## Alcance de esta documentación

La documentación se generó a partir del código fuente contenido en el
directorio `modules/` del repositorio de OpenCV.

Se incluyen principalmente:

- Clases y estructuras.
- Espacios de nombres.
- Funciones.
- Variables y miembros.
- Archivos fuente y cabeceras.
- Relaciones entre entidades.
- Código fuente navegable.
- Referencias cruzadas.
- Diagramas de clases y colaboración cuando Doxygen y Graphviz pueden
  determinarlos.

Se excluyeron directorios correspondientes a pruebas, rendimiento, ejemplos,
dependencias externas y archivos generados.

## Herramientas utilizadas

La documentación fue generada utilizando:

- Doxygen.
- Graphviz.
- Git.
